# Voix : banque de phrases, lecture par la synthèse du téléphone

Tickets VO2 (#84), VO6 (#129). Décision du 21/11/2026 : les annonces sont dites par la synthèse vocale du téléphone (Android `TextToSpeech`, hors ligne), dans la langue de l'app ; le cœur Rust produit les phrases (fr/en). L'app ne touche jamais au volume. Pas de LLM.
